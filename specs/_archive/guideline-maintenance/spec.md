# 지침 운영 개선 Spec

> 작성일: 2026-09-05 / 상태: 사용자 요청에 따른 문서 정비
> 승인 후에는 사용자 지시 없이 요구사항 수정 금지

## 목표

프로젝트 지침의 충돌·중복과 불필요한 중단을 줄이고 명시적인 승인 장치를 보존한다.

## 요구사항

- R1. AGENTS.md, 프로젝트 스킬 3개, 템플릿, README, 훅 안내의 원문·파일·행동 영향·편집안을 남긴다.
- R2. 승인 정책을 AGENTS.md로 통합하고 스킬과 템플릿의 중복 절차를 정리한다.
- R3. 명시적 승인 제거 등 권한 확대 방안은 적용하지 않고 별도 제안으로 표시한다.
- R4. 스타터와 소비 프로젝트의 문서 역할을 구분하고 실제 가능한 검증을 실행한다.

## 비목표 (Non-Goals)

- 최초 계획·Phase 진행·아키텍처·범위 확장·규칙 승격 승인 폐지.
- 런타임 스크립트, 배포 모델, 외부 서비스 설정, 전역 설치 스킬 수정.

후속 사용자 승인으로 일반 작업의 반복 승인 완화와 훅 런타임·등록·테스트 수정이 별도 범위로 추가됐다. 위 비목표는 최초 지침 검토 단계에만 적용한다.

## 제약

- 현재 요청은 문서·프로젝트 스킬 정비의 실행 근거이며 향후 코드 계획 승인이 아니다.
- 배포 스크립트의 docs 복사 계약과 context 프론트매터 키를 유지한다.

## 완료 기준 (Definition of Done)

- [x] R1~R3의 원문 검토표와 적용 여부 기록
- [x] 스킬 형식, 문서 링크와 diff 검증
- [x] 기존 훅 구문·샘플 및 임시 소비 프로젝트 부트스트랩 검증 실행·제한 기록 (전체 통과 아님)
- [x] 문서 동기화와 아카이빙
