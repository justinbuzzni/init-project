# 지침 운영 개선 Context

## 현재 상태 (3~5문장)

후속 훅 리뷰·수정은 완료됐고 macOS 회귀 테스트와 실제 CML 2.4 안내 출력이 통과했다.
사용자 요청 T1~T4 및 리뷰·수정·커밋·PR 제출이 실행 근거다. GitHub 게시 단계가 남아 있다.
중요한 발견은 Stop 등록 누락, 다른 이벤트를 CML 등록으로 오인, 공백 경로·잘못된 버전 처리,
활성 기능이 없을 때 CML 안내 누락, 완료 기능의 불필요한 리마인더, 잘못된 Stop 입력 처리였다.

사용자 요청 범위의 지침 검토와 문서·프로젝트 스킬 정비를 마쳤다.
초기 정비에서는 기존 승인 장치를 유지했고, 후속 사용자 승인에 따라 일상 작업의 재승인 요구를 완화했다. 현재 정책은 AGENTS.md가 원본이며 아래 후속 기록을 우선한다.
파일별 변경 전 인용·행동 영향·구체적인 편집안·권한 영향은 [plan.md](plan.md)의 13개 항목에 있다.
아래 초기 정비 기록의 “런타임 변경 없음”은 당시 범위다. 현재는 훅·등록 설정·회귀 테스트까지 수정했다.
