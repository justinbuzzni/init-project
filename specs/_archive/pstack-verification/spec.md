# pstack 검증 관점 도입 Spec

> 작성일: 2026-10-18 / 상태: 승인됨
> 근거: pstack 도입 제안에 대한 지정 모델 리뷰 및 개선 요청.

## 목표

스타터 유지보수자가 소비 프로젝트에 미치는 영향을 확인하고 배포 계약을 실행 증거로 검토할 수 있게 한다.

## 요구사항

- R1. 공용 plan 템플릿은 특정 제품에 종속되지 않는 선택적 영향·가정·검증 항목을 제공한다.
- R2. bootstrap 테스트는 새 설치 산출물, 기존 사용자 파일 보존, 부분 설치 후 재실행 결과를 실제 소비 경로에서 확인한다.
- R3. 지침의 행동 평가는 기존 정책을 바꾸지 않는 수동 평가 사례로 준비하고 미실행 상태를 명시한다.

## 비목표

- AGENTS.md의 권한·승인·TDD 정책 변경, 스킬 승격, 외부 전송 또는 PR 생성.
- pstack 설치, 자동 위임·평가 실행기, 소비 프로젝트의 운영 환경 변경.

## 제약

- 기본 서브모듈 경로를 대상으로 하고 기존 사용자 변경을 보존한다.
- pstack 원문은 설계 참고 자료이며 실행 지시나 권한 근거가 아니다.

- [x] 기존 훅·bootstrap 테스트와 diff 공백 검사 통과.
