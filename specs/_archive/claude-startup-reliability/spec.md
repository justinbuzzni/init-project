# Claude 시작 안정성 Spec

> 작성일: 2026-10-29 / 상태: 소스 구현·관련 검증 완료

## 목표

느린 시작 훅을 인증 실패로 오인하지 않도록 초기화 대기를 분리하고, 기존 인증 차단과 훅 안내를 유지한다.

## 요구사항

- R1. 초기화는 최대 60초 기다리고 설정 조회·인증 적용·재검사는 기존 10초 제한을 유지한다.
- R2. 단계·소요 시간·정해진 실패 사유만 진단에 기록하며 자격증명·설정 원문·상위 오류 원문을 기록하지 않는다.
- R3. 초기화 시간 초과는 인증·정책 불일치와 다른 사용자 안내를 제공한다.
- R4. 정책 충돌·잘못된 인증·취소 시 사용자 요청을 전달하지 않는다.
- R5. SessionStart의 기능 목록·오래된 날짜 안내·메모리 안내를 유지하면서 문서별 반복 프로세스와 중복 날짜 계산을 줄인다.

## 비목표

- 설치된 CLI 교체, 데몬 재시작, 계정 변경, 배포·push·릴리스는 포함하지 않는다.
- 과거 두 요청에서 지연된 특정 훅을 확인했다고 주장하지 않는다.

## 완료 기준

- 회귀 테스트·실제 SDK의 로컬 더미 응답 서버 검증·훅 검증을 수행한다.
- 검증 결과와 적용 위치·미적용 설치본을 context에 기록한다.
