# Conventions

> 마지막 갱신: YYYY-MM-DD

## 명령어

| 목적 | 실제 명령어 |
|------|-------------|
| 전체 테스트 | 미정 |
| 관련 테스트 | 미정 |
| 린트·포맷 | 미정 |
| 타입 검사 | 미정 또는 해당 없음 |
| 빌드 | 미정 또는 해당 없음 |

패키지 설정·CI 등에서 확인한 명령으로 채운다. 미정 항목은 검증 제약으로 보고하고 실행했다고 주장하지 않는다.
출력이 긴 검증은 통과하면 요약만, 실패하면 상세를 내는 형태(조용한 리포터 옵션 등)로 적는다. 통과 로그 전체가 매번 에이전트 컨텍스트에 들어가지 않게 하기 위해서다.

## 명명·문서 컨벤션

- 기능 폴더는 kebab-case. ADR은 docs/adr/NNN-title.md.
- 새 기능 문서·ADR은 specs/_templates/의 해당 파일을 복사한다.
- 상태·체크박스·검증 결과는 실제 작업과 일치시킨다.
- (프로젝트 고유의 명명·코드 컨벤션을 여기에 적는다)
