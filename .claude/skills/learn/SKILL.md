# /learn — 회고와 교훈 자산화

AGENTS.md §2.8 학습 루프의 "축적 → 승격" 실행판. 목표: 경험을 검색 가능한 자산으로 바꾸고, 반복 검증된 자산을 프로젝트의 규칙·스킬로 승격시켜 **사용할수록 똑똑해지는 시스템**을 만든다.

## 절차

1. **소재 수집**: 회고 범위(기본: 이번 세션)에서 교훈 후보를 모은다.
   - context.md의 "시도했으나 실패한 접근" / "발견된 문제"
   - 테스트 실패 → 원인 규명 → 해결에 이른 과정
   - 예상과 다르게 동작한 도구·라이브러리·환경의 함정
   - 두 번 이상 마주칠 프로젝트 특수 지식
2. **기존 교훈 대조**: `mem-lesson-list`와 `mem-search`로 이미 저장된 교훈과 비교한다.
   - 중복이면 새로 저장하지 않는다 — 대신 "반복 적용됨"으로 간주하고 4번 승격 검토 대상에 올린다
3. **교훈 저장**: 새 교훈은 `mem-lesson-save`로 저장한다.
   - `name`: 짧고 안정적인 식별자 / `trigger`: 언제 적용되는가(증상·상황) / `steps`: 검증된 해결 절차 / `failureModes`: 함정
   - `projectPath`: 메인 저장소 절대 경로 (worktree 경로 금지) / `actor`: `claude-code`
   - 일반화 검증: "다른 기능·다음 분기에도 유효한가?" — 아니라면 context.md 기록으로 충분
   - 비밀·자격증명·일회성 정보는 저장 금지
4. **승격 검토**: 반복(≈3회 이상) 회수·적용된 교훈이 있으면 승격을 **제안**한다 (승인 전 반영 금지).
   - 코딩 컨벤션 성격 → `docs/CONVENTIONS.md`
   - 워크플로우 규칙 성격 → `AGENTS.md`
   - 순서 있는 절차 성격 → 새 스킬 (`.claude/skills/`)
   - 승인되어 반영하면, 해당 lesson에 승격 사실을 남겨 중복 회수를 방지한다
5. **보고**: 저장한 교훈 / 건너뛴 후보와 이유 / 승격 제안을 요약해 보고한다.
